# Support

This project is currently pre-release.

For bugs, reproducible compatibility problems, and feature requests, open a GitHub issue with the affected version, Opera/Chromium version, operating system, steps to reproduce, and relevant non-sensitive logs.

Do not post credentials, access tokens, SSH private keys, customer data, proprietary service records, or authenticated screenshots containing sensitive information.

For security vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
