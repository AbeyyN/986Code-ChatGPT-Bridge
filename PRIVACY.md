# Privacy Policy

986Code Bridge is designed around a user-owned identity model.

## What 986Code Bridge does not do

- It does not provide or share a maintainer-owned ChatGPT/OpenAI account.
- It does not bundle a maintainer-owned OpenAI API key or access token.
- It does not upload browser cookies, login sessions, SSH credentials, or command history to a 986Code service.
- It does not store SSH passwords, passphrases, private-key material, API keys, bearer tokens, or cookies in extension storage.

## Local data

The extension may store local settings, permission choices, non-secret SSH profile metadata, and redacted command-audit metadata in the browser profile where it is installed.
Typed values, SSH command bodies, profile payloads, and URL query/hash components are redacted or omitted before local history is written.

Users can disable local command history or clear it from extension settings.

## User accounts and sessions

ChatGPT, Opera, browser, SSH, and operating-system identities remain the user's own. Installing 986Code Bridge on another browser profile or computer does not grant access to the maintainer's accounts or sessions.

## Future integrations

Any future direct AI/API integration must use per-user authorization or bring-your-own-key (BYOK). A shared maintainer credential is not an accepted architecture for this project.

## Contact

For privacy or security concerns, use the repository's documented support or private vulnerability-reporting channels.
