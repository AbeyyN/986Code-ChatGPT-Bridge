Optional coordinate-level mouse and keyboard input. POWER tier alone does not grant this Chromium permission.

POWER is disabled by default. The native host enforces POWER again before SSH execution.

SSH profiles

Profiles are stored by the native companion under the current Windows user, not in browser extension storage. Passwords, passphrases, tokens and private-key material remain outside the extension.

Privacy & logs

History is local metadata only. Typed values, SSH commands, profile payloads, tokens, cookies and URL query/hash data are redacted or omitted before storage. The secure control plane binds to 127.0.0.1 only and uses an ephemeral per-instance bearer token stored on the native side.
