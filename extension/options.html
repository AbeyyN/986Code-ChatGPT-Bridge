986Code has no shared ChatGPT account, developer API key, password vault, or central user credential. Each installation uses the user's own browser/ChatGPT session.

Debugger / CDP

Optional coordinate-level mouse and keyboard input using Chromium DevTools Protocol.

Native Messaging

Optional local companion for SSH, PowerShell, CMD, and OS-level operations.

SSH profiles

Profiles store metadata only. Passwords, passphrases, tokens and private-key material are blocked from extension storage; authentication belongs to the user-owned native/OS layer.

Privacy & logs

History is local metadata only. Typed values, SSH commands, profile payloads, tokens, cookies and URL query/hash data are redacted or omitted before storage. This build does not upload command logs to a 986Code service.
